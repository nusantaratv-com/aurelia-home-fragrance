AURELIA — Home Fragrance

Elegant candles, home fragrances and thoughtful accents for warm, beautiful spaces.



Overview

AURELIA is a premium-inspired home fragrance ecommerce concept created around candles, diffusers, room fragrances and decorative scent accessories.

The brand combines warm neutrals, soft ivory, botanical greens, amber tones and subtle gold details to create a calm, refined atmosphere. The goal is to make fragrance feel like part of the home's visual identity, not simply another household product.

Product Photography Standards

Product imagery is a core part of the AURELIA experience.

Every product image should follow these rules:

One distinct photograph per product

No repeated product photographs

Product clearly visible from edge to edge

Centered composition

Correct visual scale

Clean and uncluttered background

Consistent lighting

No accidental cropping

No browser screenshots

No prices embedded inside photographs

No buttons or website interface inside photographs

Local image assets whenever possible

Optimized image file sizes

Product cards should give each item enough breathing room so that candles, diffusers, bottles and accessories never appear tiny or awkwardly cropped.

Design Principles

Warm — AURELIA should feel inviting rather than clinical.

Cohesive — Packaging, photography, color and interface should work as one identity.

Timeless — The design should avoid short-lived visual trends wherever possible.
